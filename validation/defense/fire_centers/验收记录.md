# 火球与炎爆的爆炸中心验收

2026-10-16，Godot 4.7.1。当前规则见 [火焰词条库](../../../docs/DEFENSE_FIRE_TERMS.md)及 [ADR-0023](../../../docs/adr/0023-projectile-collision-and-spread.md)。

## 修正

火球命中接口自行读取实际被击中目标当时的 `target.pos`，不再接受外部爆炸坐标。主爆炸、延迟副爆炸和余烬共用这个位置快照；命中后目标移动或死亡，区域均保留原位置。炎爆每次穿透命中分别建立一组区域。弹体沿原方向继续，寒冰折射仍从弹体接触点发射。

## 位置和真实伤害

新增 `tests/test_defense_fire_centers.gd`，272项断言通过；先以旧实现运行可复现中心和范围错误，再验证修正后的实现。

| 场景 | 验证结果 |
|---|---|
| 普通火球被途中敌人拦截 | 使用首个实际命中目标的位置，与原瞄准目标、弹体接触点均有区分 |
| 命中目标随后移动或死亡 | 主爆炸、副爆炸、余烬的领域位置及表现快照保持命中时坐标 |
| 基础范围 | 主爆炸和余烬半径150；边界内外均以实际扣血检验 |
| 范围强化及多重爆炸 | 主爆炸270、副爆炸351、余烬270；延迟副爆炸不重新读取目标坐标 |
| 炎爆单步穿透三人 | 按实际接触顺序命中3名不同敌人，分别生成3个效果，共9个；每组位置、范围、实际扣血均独立验证 |
| 余烬 | 第1、2、3秒各真实结算一次；移动和死亡均不使区域跟随目标 |

伤害用例选择201和204，攻击力固定100、暴击及防御干扰关闭，因此主爆炸200；205副爆炸100，余烬每跳100。强化范围的每组边界探针最终结果如下；普通火球及炎爆三次穿透均执行同样检查。

| 探针位置 | 主爆炸 | 副爆炸 | 三跳余烬 | 总扣血 |
|---|---:|---:|---:|---:|
| 主爆炸/余烬边界内0.25单位 | 200 | 100 | 300 | 600 |
| 主爆炸/余烬边界外0.25单位 | 0 | 100 | 0 | 100 |
| 副爆炸边界内0.25单位 | 0 | 100 | 0 | 100 |
| 副爆炸边界外0.25单位 | 0 | 0 | 0 | 0 |

圆形范围按现有战斗契约包含目标身体半径，即目标位置到中心距离不超过“技能半径+目标身体半径”。探针设置在该有效边界两侧；不是只比较配置值，也不是以贴图大小推断伤害。另有探针位于新旧中心圆的差集，确认旧接触点范围已经失效。

`tools/validate_fire_centers.gd -- --capture` 共1404项断言通过。保存普通火球、炎爆各33张720×1440原生帧，覆盖0至4096毫秒；每次创建及后续存续均核对中心和半径。目标在首次命中96毫秒后向右移动350单位，爆炸和余烬保留原处。

炎爆原生飞行分别在256、576、912毫秒命中，三个位置的Y坐标为1019.76、719.76、419.76；每次创建主、副爆炸及余烬，三个中心互不替换。静态对照可见首个目标已经离开，原位置的余烬仍在。GIF按实际逻辑速度回放，只裁切原生截图并在画面外添加说明，未重绘特效。

首个目标移动350单位后离开余烬范围，仍位于较大的副爆炸范围内；原生记录最终实扣主爆炸200、副爆炸100、余烬0，生命99700。后两名目标保留原位，处于相邻副爆炸重叠处时会额外受到对应伤害，符合范围独立于弹体命中次数的契约。

原生场景使用现有领域工厂及合法词条接口建立隔离夹具，用于检查实际运行和显示。它不代表自然对局必定获得这些强化。原有7°寒冰箭、5°火球、齐射数量、穿透和折射专项同时重新执行，记录见 [弹道验收](../projectiles/验收记录.md)。
