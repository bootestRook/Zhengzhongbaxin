# 雕像页初版验收

2026-10-17；Godot 4.7.1；L2 关联回归。对应用户批准的六部位装备、测试宝石、参考图操作布局及满孔替换流程。

## 已实现

- 雕像接入底部主导航，与英雄、战斗互相切换；复用头像、名称、编号、等级、经验、体力、钻石和金币。
- 上部保留雕像、战力占位和右侧二列三行装备。头部/手臂、胸甲/裤子、鞋子/手套，每部位五孔。
- 默认六件已穿戴，每部位一件同款备用装；左右独立卡显示当前与候选，右侧按钮替换，旧装备返回背包。没有卸下、制作、锻造或分解。
- 每部位七种品质测试宝石（灰、绿、蓝、紫、橙、红、彩），每种两颗，背包按部位与类型堆叠，可筛选。左侧详情与右侧五条镶嵌行遵循用户操作参考图。
- 空位直接镶嵌；满五孔后点击镶嵌，压暗背景并显示“请选择要替换的宝石”。点击指定右侧宝石替换并返还旧宝石；点击空白或 Esc 取消选择，回到未压暗的详情。普通详情再次点击空白或 Esc 关闭。
- 装备和宝石图标使用新制墨线资产。换装保留该部位宝石，不影响任何战斗属性。
