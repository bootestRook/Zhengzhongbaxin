# 初始技能与特效核对

2026-10-14，Godot 4.7.1。针对召唤偏位、怪物死亡残留和初始技能特效过多的反馈。

## 修复

- 英雄入场和复活：删除通用 `battleEffect:summon`，改用源客户端 HeroSum1/HeroSum2 对应的 `summon2`、`summon3`。同一出生脚点，枢轴 `(0.5, 0.8)`，分别绘制在角色后方和前方，各播放一次五帧、500 ms。
- 普通怪物：死亡时保留最后一帧姿态，90 ms 后接管缩放，按 260 ms 的消退曲线缩至零；350 ms 后不绘制身体和影子。不会因缺少 die 动作而回退到循环待机。
- 首领：采用源客户端的 300 ms 膨胀、100 ms 扩散淡出身体时序。此次未实现其粒子和慢动作，不能称为完整首领死亡特效验收。
- 死亡逻辑：保留尸体存续、DeathAfter、死亡施法和英雄复活时间；显示消退不提前改变结算。
- 技能：删除近战额外通用命中特效，以及弹体结束后再播放原特效的重复路径。原技能弹体在自身生命周期内显示。

Godot 中打开的旧局进程启动于 05:44:15，而资源索引于 06:04:46 更新、运行目录于 06:05:15 重建。组合根只在启动时读取目录，旧局不会重新建立图集坐标映射；必须重新启动游戏使用新目录。与原始 PNG 比对的四组资源（Mage4、normal_0、normal_2、meimo）像素一致。
