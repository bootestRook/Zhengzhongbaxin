## 实际修正

1. 区分怪物入场警戒线 Y=550、英雄通常索敌线 Y=700、退线索敌线 Y=850、后方威胁线 Y=600。数值由当前 battleBar3 的 heroPoint 与 line1–4 配置推导，删除了未使用的 back_y。
2. 近战比较后方威胁和前方候选，必要时先横向归位；索敌释放出生位置锁，避免追击后不能归位。远程在攻击间隔、出生位置仍能覆盖当前目标时归位。最后/滞留首领且敌人不超过 8 个时允许越过巡逻线收尾。
3. 怪物成长补上关卡自己的 hp_up、atk_up；此前只读取章节修正。普通、精英和首领共享修正后的公式。
4. 入场加速在 Y=550 结束，按 7 秒衰减；入场加速与减速百分比相加，避免将减速和入场加速相乘。速度为零时保持待机动作。
5. 普通小怪和精英均不显示血条。英雄血条保留；受伤首领血条保留。

## 所有怪物数值与移速

[monsters.csv](monsters.csv) 保留全部 201 条记录的生命/攻击基础与成长、攻速、移速、攻击目标数、阻挡配置、技能、特征及完整字段。空槽明确标记为无效单位。

未加入关卡特殊增益的主线数值公式：

- 生命成长等级 = 关卡 ID + 章节 hp_up + 关卡 hp_up + 精英加成。
- 攻击成长等级 = 关卡 ID + 章节 atk_up + 关卡 atk_up + 已累计波次攻击成长 + 精英加成。
- 最大生命 =（生命基础 + 生命成长 × 生命成长等级）×（1 + 累计波次生命成长 / 100）×（1 + min(关卡 ID, 100) × 0.001）^floor(出生波次 / 3)。
- 攻击 = 攻击基础 + 攻击成长 × 攻击成长等级。防御特征另按当前攻击计算。
- 基础移速分布为 20、25、28、30、32、40、45、55、60、65。前五波入场速度分别加 200%、160%、120%、80%、40%；进入 Y=550 后使用基础移速和状态修正。

例如第 3 关第一波普通鼠（101）的最大生命为 192、攻击为 23、基础移速为 40。第一波无减速时刚入场速度为 120；入场加速会逐步衰减，不能把 40 当作整段移动的恒定速度。

[monster_expected.json](monster_expected.json) 从配置与已核实的源公式产生期望值；[monster_runtime.json](monster_runtime.json) 记录实际领域创建值。88 个有效怪物 × 4 个关卡（1/3/20/50）× 5 个波次（1/5/12/20/30）× 3 个类型（普通/精英/首领），合计 5,280 种创建条件、31,680 项属性比较，无差异。这个结果证明数值创建路径，不能代替每种怪物的原版动态战斗验收。
