# 结算实机依据与验证边界

2026-10-14，在用户已打开的雷电模拟器9中观察三选一、暂停、退出和结算英雄资料。退出暂停页直接进入关卡结束，没有二次退出确认。Android screenrecord 保存为 `result_reference_motion.mp4`；末帧去除左右黑边后为 `result_native_reference_960.png`。

用户提供的结算截图是四英雄、54%进度、两个雕像和五格奖励的布局依据。此次实机退出发生在第2波，显示6%、两个英雄及“未获得奖励”；参考账户的历史100%属于该账户，工程不得照抄。

实机顺序为战场冻结、暗化模糊、武器横幅弹出与回弹、进度增长、关卡与历史、英雄卡和统计增长、MVP、雕像、奖励标题。青色光晕持续转动，结算英雄使用待机动作。英雄卡右上角 i 打开已有属性资料，确认结束结算。

工程 `DefenseResult` 在 finish 时保存冻结的本局数据，`DefenseResultPanel` 只呈现；重绘不重播、退出取消 Tween，英雄详情不能恢复战斗时钟。最好进度仅保存于本进程的 Session，尚未添加跨启动存档。

生产结算截图 `result_actual_*` 来源于真实固定步战斗、真实选项与退出输入。`result_reference_fixture_*` 是明确标记的布局夹具：四英雄、54%和五奖励格只为复核用户截图布局，额外经验/装备条目未作为生产掉落。`result_empty_*` 与 `result_victory_*` 分别验证零英雄退出和领域胜利接口。当前招募上限为四英雄。

冻结的50关普通 reward 配置为空，当前生产显示“未获得奖励”。本改动没有增加局外库存、首次奖励规则或服务器随机掉落；不把用户截图上的奖励数字写入生产结果。普通配置引用只允许已核对的两种资源图标，未知引用由数据编译拒绝，不以钻石图标兜底。

检查尺寸为960×1920、720×1440、540×1080。每档包含真实战斗退出、四英雄五奖励格布局、零英雄、胜利、英雄详情；动效另有分阶段采样。图集回归对全部15页重排、扩展页面尺寸并移动所有精灵区域，比较23个状态的三档截图。最终测试及视觉修复判定见同目录对应日志与 review 文件。

图集像素对照通过生产Intent和公开表现接口进入界面，每组先断言目标层可见，再冻结表现时钟进行原图/重排图比较；鼠标命中另由场景测试与结算持续运行捕获验证。二者分别证明资源绑定与交互，避免选择Tween回调在一对像素采样之间改变领域状态。
