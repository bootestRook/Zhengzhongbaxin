# 子弹与弹道验收

2026-10-16，Godot 4.7.1，当前工程原生 Compatibility 渲染。规则见 [ADR-0023](../../../docs/adr/0023-projectile-collision-and-spread.md)。

## 已验证的行为

| 项目 | 结果 |
|---|---|
| 多重射击 | 一个主目标、基础3条弹道，齐射仅使总数变为4；1个及5个候选敌人的数量均相同 |
| 寒冰角度 | 基础0°、−7°、+7°；齐射额外−14°；主箭瞄准目标身体中心 |
| 火球数量与角度 | 强化后1/2/3颗，依次为0°、−5°、+5°，同时发射 |
| 实际位移角度 | 连续帧位置反算，寒冰约−7.00009°、+6.99998°、−14.00000°；火球约−4.99994°、+5.00010°，误差均小于0.01° |
| 寒冰穿透 | 同一颗主箭最多接触2名不同敌人；5名重叠敌人也只伤害2名，保留原弹体编号，不另生穿透段 |
| 高速与顺序 | 单步640世界单位的路径能检测全部途中候选，按接触先后、同距单位编号结算；逆创建顺序不改变结果 |
| 炎爆穿透 | 单颗弹体最多接触3人，逐次产生3次爆炸；范围重叠伤害独立于弹体接触次数 |
| 火球爆炸中心 | 主爆炸、副爆炸、余烬以实际命中瞬间目标位置为固定中心；炎爆每次穿透分别取当次目标坐标，见[中心与伤害范围验收](../fire_centers/验收记录.md) |
| 折射 | 从真实接触点派生，继承伤害与冰冷；两次主箭接触产生两根折射箭，各自最多命中1人，不继续派生 |
| 清理与失效目标 | 目标死亡不会让已发出的直线弹消失或转向；同弹不重复命中，派生链正常结束 |
| 普攻与出手词条 | 普攻保留既有单箭路径；集中、连击、箭雨不因穿透或折射重复触发，击退保留同组限制 |
| 原生尺寸 | 寒冰齐射与三火球在960×1920、720×1440、540×1080分别保存并校验尺寸 |

领域专项：`tools/validate_projectiles.gd` 共142项断言通过。带原生截图执行时共244项断言通过，无脚本错误。完整工程回归已通过，结果见本文末尾。
