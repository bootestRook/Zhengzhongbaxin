# 战斗复刻初版说明

当前玩法已按用户批准的[体验优化](DEFENSE_EXPERIENCE.md)改为五人、二十波及职业复活；本页原四人、三十波、雕像选项与旧复活公式属于历史参考。

日期：2026-10-13。工程：T8-demo-16。基线：Godot 4.7.1。

本文保留初版验收记录。2026-10-14 的战斗规则修订及当前差异见 [战斗规则对照与验收](DEFENSE_COMBAT_FIDELITY.md)；本文后面的初版性能、断言数和差异列表不是当前结果。

## 当前可玩范围

主界面选关 → 初始英雄三选一 → 自动守城 → 招募英雄、选择强化及雕像 → 点击宝箱 → 英雄死亡倒计时复活 → 完成当前刷怪表中的波次和特殊行，或城墙归零失败 → 重开或返回主界面。暂停、倍速、静音、英雄技能详情和伤害/治疗统计可用。

| 内容 | 本次接入 |
|---|---|
| 主线 | 当前开放 1–5 关，每关 20 波，共 100 波 |
| 刷怪 | 逐行确定怪物 ID、数量、秒级触发时间、批次间隔、单次刷新数量和分布方式；空白/2/3 识别普通/精英/首领 |
| 怪物 | 当前五关表格引用的怪物模板，逐行应用攻击、血量和血条数量 |
| 英雄 | 图鉴 18 条，17 名可招募；战狂不进入抽选 |
| 局内选项 | 331 条可抽取主线选项，使用前置、互斥、次数和所属英雄条件 |
| 技能表现 | 21 类弹体行为入口、技能连锁、伤害/治疗/护盾、召唤、常见控制和周期伤害 |
| 资源 | 13 张 4096 图集、7,523 个精灵记录、843 个动画记录、字体、89 个运行音频文件 |

局外输入统一为英雄等级 1、无装备/宝石/符文，城墙基础生命 3900；英雄本身的基础差异保留。完整局内成长继续生效。

## 来源与更新

来源为 `F:/T8demo/正中靶心2_拆解_20261013` 下的当前版本配置、`09_当前客户端补充` 和 `10_复刻前研究_20261013` 的实机证据。运行所需数据已经冻结在工程内，开游戏不需要原拆解目录。

技能缺口 510、608、1072 被记录在导入审计和运行诊断中，没有替造内容。战狂缺少当前版专属技能树，也没有用其他英雄技能冒充。

## 验证依据

- 领域与场景测试覆盖 50 关波次数、出生槽位和 Boss 引用；非法选择；强化对真实技能实例的影响；冻结、护盾吸收与到期；死亡复活；城墙归零失败；隐身索敌和两种掉血触发。
- 17 名英雄逐个在独立战斗中验证能够产生实际伤害；炼金术士先进行入场药剂选择。
- 两次同种子、同选择的第一关完整回放，结果及选择历史一致，均到达第 30 波并击败三个 Boss。
- 原生窗口已检查主界面、50 关列表、三选一、实际战斗、技能详情、暂停及结算返回流程。截图保存在 `validation/defense/`。
- 30/100/300 敌人的 CPU 固定步加快照基准约 0.53/1.76/6.16 毫秒，见 `validation/defense/performance.json`。这是本机无渲染逻辑基准，不是 300 怪时的画面帧率或 Web 性能承诺。

最终 `project.py check` 通过：577 项 Godot 断言、13 项 Python 管线测试、架构与来源指纹检查、导入及启动烟测；日志为 `validation/defense/project_check.log`，没有 ERROR/SCRIPT ERROR 标记。自动回放证明所测路径；不能据此声称所有英雄的全部随机构筑均已与原客户端一致。

独立界面复核结论为 `ship`，范围限于上述七个静态界面证据。`启动游戏.cmd` 已实际执行并打开主界面。旧测试实例退出时出现一次 WASAPI 输出设备失效日志，新启动实例正常；尚未验收音频设备热插拔。

## 初版仍有的差异

1. 已接入完整相关配置，核心行为由独立实现解释。复杂触发时机、部分目标筛选、特殊被动之间的结算顺序、弹体轨迹与特效时序仍需逐分支对照；没有“全部技能精准复刻”的验收结论。
2. AI 包含范围索敌、移动、攻击、冷却、控制、复活、召唤及进攻城墙。单位拥挤避让、身体阻挡、完整仇恨优先级和各 Boss 专属战术尚未逐项还原。
3. 伤害包含固定防御扣减、暴击、闪避、吸血、护盾与减伤；部分边界公式及原客户端按阵营区分的处理顺序使用初版近似。
4. 宝箱已改为预抽词条、点击复核、居中单张固定奖励，并覆盖同品质替换及降品质拆箱；落地尺寸、品质光柱与悬浮动作已对照。飞入、扬尘和开盖过程尚未逐帧验收，见 [宝箱对照](DEFENSE_CHEST_FIDELITY.md)。结算保留局内统计，不连接外部奖励和养成。
5. 动画已使用原始动作帧，尚未逐个验收全部动作反向循环、击中帧、遮挡和缩放。原界面的完整动效也未逐帧对齐。
6. 没有中途存档恢复、商城、广告、联网、局外养成系统或平台导出包；每次启动从主界面开始。

后续应按“单英雄完整分支 → 组合交互 → Boss 行为 → 表现时序”补验，优先把上述差异缩小，避免继续扩关掩盖规则误差。
