# ADR-0029：逐行怪物 ID 刷怪与五关测试目录

状态：接受。日期：2026-10-19。

刷怪配置改用 `关卡波次配置-1测试关卡` 单表作为人工编辑入口。每一行直接持有怪物 ID、数量、触发时间、批次间隔、单次刷新数量、分布方式以及逐行攻击、生命和血条数量；运行时不再读取怪物组、权重或 `怪池成员` 子表。

`波次类型` 的空值、2、3 分别编译为普通、精英、首领。特殊行的数量、波次和触发时间完全由表格决定，胜利条件与战斗面板按实际特殊行生成，不再假定固定的两个精英和一个首领。触发时间以秒填写，编译为毫秒；数量波动按 `数量 × [1-系数, 1+系数]` 采样并向上取整。刷新间隔和单次刷新数量共同决定当前波次的批次，实际批次数量受该行剩余数量限制。

`分布方式` 1 为随机位置，4 为中间位置。`血条系数` 作为血条数量保存和显示，不参与攻击或生命倍率。首次刷新数量字段从表结构删除。攻击和生命系数必须是粘贴后的实际数值，不能保留公式或外部链接。

测试目录只生成关卡 1 至 5，源表中的 1001 至 1005 映射为运行时的 1 至 5。运行 schema 升为 14，规则 schema 升为 6；不保留旧怪物池和固定遭遇格式的加载路径。

验证覆盖导表源校验、生成目录的五关和逐行字段、确定种子下的批次与数量、分布位置、血条数量、特殊行清除和真实战斗胜利。由于公共数据 schema、刷怪运行时和关卡 UI 同时变化，完成前执行关联回归及完整工程检查。
