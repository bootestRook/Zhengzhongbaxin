# ADR-0013：关卡生命数值调整

状态：接受。日期：2026-10-15。

当前数值：2026-10-15 按用户最新要求重新采用调参后的配置，第 2 关敌方生命系数为 0.51。

用户要求把当前第 2 关调整到约 40%–50% 的模拟通关率，并确认统一降低该关敌方生命。原始 reference.json 保留研究来源，人工调整集中放入 data/source/defense/level_balance.json，不修改共享怪物模板。

新增 schema 1 源表，以关卡 ID 声明 enemy_hp_multiplier。编译器验证已知关卡、字段及有限正数，向每个运行关卡写入明确的生命系数；未调整的关卡编译为 1。运行目录升级为 schema 6，仅接受当前格式。

敌方普通怪、精英和首领在原有等级、精英及波次生命成长全部结算后应用该关卡生命系数。英雄、召唤物、攻击、速度、刷怪数量和随机流契约沿用现有规则。共享领域代码读取关卡字段，不根据关卡 ID 分支。

采用合法招募、强化和宝箱操作进行完整二十波模拟。候选数值使用固定校准种子，最终数值使用独立种子复测；报告记录选卡策略、样本量和配置指纹，模拟胜率不作为真人胜率。
