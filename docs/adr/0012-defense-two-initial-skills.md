# ADR-0012：双初始技能及对应分支

历史决策：2026-10-16已被 [ADR-0014](0014-defense-hero-roster-v2.md) 替代，以下保留原批准快照。

状态：接受。日期：2026-10-15。

五名可选英雄招募即获得两项基础技能：勇者圣盾/践踏、火焰术士火球术/炎枪、德鲁伊治疗药剂/荆棘、游侠多重箭/集中、黯影毒刃/刺杀。沿用现有施法、计数、概率和冷却；圣盾沿用现有自身攻击计数，不借此调整规则。

新增人工源表 `data/source/defense/hero_skills.json`，schema 1，按英雄声明两项基础选项、实际触发技能和所属图标组。构建期完成分支归属、前置及互斥重写，删除五英雄未保留的独立技能树，基础解锁退出抽取池，原有品质、次数及零权重分支保持不变。荆棘继承原自然之力的召唤属性被动，供荆棘后续食人花使用；不解锁原植物攻击。原始 reference.json 不修改。

运行目录升级为 schema 5，移除 `initial_option`，统一使用 `initial_options` 列表。选项记录 `root_option`、基础项记录 `trigger_skill`，用于逐技能等级与冷却快照；不提供旧格式兼容或回退。实例化逐项应用初始选项；招募预览展示两项已学技能。所有选择途径共用裁剪后的选项目录。

固定双图标按钮与等级标签保存在场景中，底栏、招募卡及英雄详情共同读取这份数据。强化/宝箱卡只展示当前候选词条。技能说明按英雄槽和技能槽分别识别；查看不会确认选择或暂停战斗。保留现有图集、纸卡、字体与三档等比缩放。

验证源表错误与引用、初始技能实际触发、跨英雄属性及强化生效、被删除树不可获得、合法完整对局、双图标鼠标交互及三档原生截图，再执行完整工程检查。
