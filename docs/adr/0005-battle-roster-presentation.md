# ADR-0005：局内战场与英雄栏表现

状态：采用。日期：2026-10-13。

按用户图2和雷电实机还原 960×1920 局内战斗构图。保留 ADR-0004 领域坐标及动作状态的所有权，表现不改变规则结果。

- 英雄栏固定四个 `roster_card.tscn` 实例，显示纸框、原有角色动作、真实生命、初始技能图标、同技能组强化次数及冷却。空格保持背景，不显示无效按钮。
- 快照增加英雄初始技能的显示字段；冷却来自领域技能实例及普攻计时，暂停和选择不推进。没有新增保存、随机或跨 Feature 契约。
- 怪物信息入口显示本关冻结配置；宝石属性入口仅在选择时出现。英雄栏固定头像与技能两个按钮：头像打开属性页，技能图标显示该英雄初始技能的配置说明，并保持战斗和选择状态不变。
- 暂停页固定六个画像、退出/继续和伤害显示选项，模糊背景保持原选择可见并锁住选择操作；点击画像显示对应说明，点击纸框外返回暂停。
- 英雄 i 使用顶部属性栏，并支持展开；贡献度与怪物列表使用可开关的非暂停浮层。列表项由当前队伍与本关怪物配置创建。
- 空槽采用既有 gem 纹理，首领纸面采用既有 common 纹理；资源导入使用原子替换，保留音频绑定和来源信息。
- 战场采用中央裁切，背景、单位、弹体、宝箱、文字共用同一投影；普通怪满血隐藏血条，护盾只随领域状态显示。
- 截图中的模拟器按键提示不写入游戏。实际关卡、角色、成长和状态由本局决定，不为静态图伪造数值或护盾。
- 技能说明使用固定 `skill_tooltip.tscn` 的纸面气泡，随内容计算高度并保持在画布内；同图标、纸面、外部点击及 Esc 可关闭，关闭不会改变原有暂停状态。

验证：三个竖屏尺寸的原生渲染，实鼠标英雄/技能/怪物详情链，生命、复活与冷却读回，以及完整项目检查。
