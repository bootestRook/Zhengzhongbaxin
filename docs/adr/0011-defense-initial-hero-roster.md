# ADR-0011：初版局内解锁范围

状态：接受。日期：2026-10-15。

初版默认解锁勇者、火焰术士、德鲁伊、游侠、黯影五名英雄。其他英雄及其词条暂不作为局内候选。

`data/source/defense/rules.json` 使用 schema 3，增加必填的 `unlocked_heroes` 列表，当前为 `[1, 2, 4, 13, 17]`。拒绝旧 schema、空列表、重复或非整数 ID、未知英雄及缺少初始技能的英雄，不提供迁移或默认回退。运行目录继续使用现有 schema 4 包装，规则 schema 独立验证。

保留完整英雄、词条和技能 Definition，`available` 继续表示内容资料完整。Catalog 的可选英雄集合同时要求资料完整与规则已解锁；Choices 统一约束招募、强化、指定奖励、宝箱预抽及拾取重验，并在确认候选时再次检查。单位工厂负责实例化已有 Definition，玩家选择权限由 Choices 管理，不把解锁条件分散到战斗、技能或表现层。

本次不新增账号养成、存档、解锁按钮或奖励，不改变五人上限、招募概率、技能数值、品质权重和随机流。图鉴继续允许查看已有资料。验证生产默认集合、抽取与刷新、锁定英雄及词条的确认拒绝、宝箱与指定奖励、无效规则和合法完整对局。
