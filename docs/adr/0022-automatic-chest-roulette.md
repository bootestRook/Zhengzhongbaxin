# ADR-0022：宝箱自动转盘奖励

后续决策：触发来源、最终首领奖励、空库提示和中央布局以[ADR-0024](0024-elite-boss-reward-trigger.md)为准。下文保留初版决策记录。

2026-10-16。用户要求宝箱掉落后自动触发转盘，先决定获得数量，再决定词条；动画点击跳过，结果再次点击关闭。

移除落地箱、点击拾取、预抽单项、同品质替换和拆箱。普通/精英沿用20/10000掉落率；非最终首领触发一次转盘，最终首领进入结算。数量1、2、3、4的权重为50、30、15、5，不设0档。只抽已招募英雄当前合法、未达次数上限的强化，同次排除重复词条；每次应用后重新检查前置，允许本次奖励解锁后续候选。候选不足时发完合法候选，空池不弹转盘。

领域Loot持有待处理队列和当前奖励，复用命名defense.loot随机流。每个奖励先一次性抽数量，再逐条抽取并通过Upgrades实际应用，记录history后进入reward阶段；动画仅表现既定结果，当前奖励的播放、跳过和关闭均不重抽该奖励；打开下一份排队奖励时才进行下一次正常抽奖。reward阶段暂停领域时钟，关闭必须匹配奖励编号，拒绝重复或过期输入。多掉落排队，完成升级/指定奖励后自动处理；雕像生命归零或最终胜利优先结束并清空队列。

规则源新增四档权重并严格升级为schema4，生成目录升级为schema9；不保留旧schema、旧箱子字段或拾取Intent。静态界面保存在独立tscn，表现只提交reward_close Intent；数量滚动、转盘减速和奖励揭晓共用可跳过的本地时间轴与独立表现随机流。词条标题和正文直接读取原始Definition，不改写用户原文。

验证数量边界/权重、先数量后词条、合法性/前置/次数/去重、真实效果与历史、同种子重放、跳过不改结果、多次点击、排队/暂停/结束清理、真实掉落和三档窗口输入。
