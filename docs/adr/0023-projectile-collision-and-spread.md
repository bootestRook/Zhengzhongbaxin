# ADR-0023：弹体穿透、折射与扇形发射

2026-10-16，用户批准。替代 ADR-0018 的逐颗分目标和 ADR-0020 的多目标、多路齐射及命中后另生穿透段规则。

## 决策

多重射击选择一个主目标，基础三条弹道，齐射仅增加一条，总计四条；角度按主弹0度、左7度、右7度、左14度依次展开。目标不足不减少数量，无合法目标不施放。火球同样只选择一个主目标，按强化发射一至三颗，角度为0度、左5度、右5度。弹体发射后按方向直线移动，主目标移动或死亡不改变弹道。普通单体普攻保留锁定追踪。

沿用 hero_roster 人工源，在火球和寒冰能力中加入必填 spread_degrees。寒冰 copies 表示整次技能出手的弹道总数，基础3、齐射增量1；删除旧的逐目标复制语义。派生弹体不重新触发集中、箭雨或连击，连击另执行一次完整出手。

现有弹体工厂把 damage_num 转为直线弹体独立的 hit_limit。移动模块对整段位移做连续矩形碰撞，按首次接触比例、单位编号排序；逐目标检查命中上限，单颗弹体仅命中同一单位一次。范围伤害和持续脉冲仍使用各自 remaining，不以穿透计数替代。碰撞消耗次数，实际伤害继续遵循现有闪避、抗性、护盾等契约。

穿透沿同一弹体、同一方向继续，不生成第二颗穿透弹。寒冰穿透+1即最多命中2人，炎爆术+2即最多3人，每次命中分别冻结当次目标的位置（target.pos），主爆炸、延迟副爆炸和余烬共享该固定中心，特效与伤害范围一致。首个实际命中的目标可能不同于发射时的瞄准目标；后续目标移动或死亡不改变已建立区域。折射由主箭每次直接接触后额外生成一根箭，从实际接触点朝300范围内最近的另一名合法敌人发射，同距按编号排序；不穿透、不再次折射。子箭忽略触发它的敌人，其他弹体各自记录命中，共享原出手对同目标最多成功击退一次的预算。

命中规则继续属于 defense domain。表现消费弹体实际方向、位置和事件，不参与伤害决定。不新增全局服务、第三方依赖、跨 Feature 依赖或 Save/RNG 契约。

## 验证

覆盖源配置非法角度和数量、3/4条寒冰弹道及1/2/3颗火球、相对瞄准方向的7/5度实测、目标移动/死亡、沿途拦截、高速漏碰、逆创建顺序、密集重叠上限、同弹去重、每次穿透爆炸、真实折射扣血及派生终止、同组击退。保存真实领域实例和战场渲染的多时点截图及角度/位置记录，完成 project.py check；测试夹具不作为自然对局取得满强化的证据。
