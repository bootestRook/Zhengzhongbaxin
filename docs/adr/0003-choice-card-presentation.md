# ADR-0003：局内三选一纸卡表现

状态：接受。日期：2026-10-13。

用户要求按所附图2还原局内三选一，并补充出现动效。沿用 ADR-0002 的本地研究资源范围和 960×1920 画布。

- 固定三张卡片共用 `scenes/defense/choice_card.tscn`，在主场景中实例化；卡片、选择面板和 HUD 各自负责表现。
- 编译现有冻结数据时补全英雄的种族/职业标签、选项的图集图标引用，并校验引用；由原表生成，禁止手改生成物。没有图标的源记录使用空引用，不冒充其他技能。
- 选择面板读取现有领域快照，通过原有 `choose`、`refresh` Intent 提交操作。没有新增领域状态、随机流、存档契约、Autoload 或依赖。
- 入场采用遮罩淡入、三卡错峰缩放回弹、卡后光束渐显；刷新重播卡片入场。确认选择时锁定输入，完成短反馈后提交一次 Intent。动画只延迟表现提交，不产生规则结果。
- 详情可阅读完整技能文本，关闭后返回原选择；暂停恢复不重播入场。取消、退出或快照变化会终止旧动效，避免旧回调提交新一轮选择。
- 图2是静态视觉依据，不能证明原客户端动效时长；本次时序属于独立实现。原有离线养成输入继续使用英雄等级1，不伪造截图中的不同英雄等级或广告系统。

验证：真实鼠标输入链覆盖选择、详情、刷新、重复点击、暂停恢复；检查英雄、强化、雕像状态及默认/参考比例的渲染，运行完整 `project.py check`。
