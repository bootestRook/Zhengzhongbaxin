# ADR-0007：退出与胜负结算表现

状态：采用。日期：2026-10-14。

按用户结算截图与雷电实机退出过程，替换旧文字结算弹窗。固定骨架保存在 result_panel.tscn，动态英雄、雕像和奖励条目使用独立场景；所有图片仍按名称读取当前图集。

领域在 finish 时冻结本局进度、首领状态、英雄统计、已选雕像与已有普通奖励配置，保存进程内的关卡最好进度。结算动效只展示这些事实，不能决定规则、改动数值或发放奖励。服务器随机掉落及尚未接入的首次奖励不由界面补造；当前冻结普通奖励配置为空时显示实机已有的“未获得奖励”。最好进度由 DefenseSession 持有；本次没有新增存档、局外库存、服务器或跨 Feature 依赖。

入场按实机记录分阶段：暗化模糊、横幅缩放、进度增长、英雄与统计、MVP、雕像与奖励。重复快照不重播；确认或切换状态取消 Tween，详情不恢复领域战斗。结算英雄 i 继续使用现有属性面板。确认返回主界面。

验证：退出、失败、胜利、零到四英雄、重复快照、详情关闭、进度与奖励冻结、三个竖屏尺寸与动效采样；继续执行图集重排回归及完整项目检查。
