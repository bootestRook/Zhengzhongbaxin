# ADR-0010：升级时混抽招募与强化

状态：接受。日期：2026-10-14。

用户批准取消固定招募等级。开局仍单独招募第一名；以后每次升级的每个卡位按25%招募、75%强化混抽，允许同轮0至3张招募卡。强化保留现有英雄与品质权重。满五人不出招募，已招募及死亡英雄不重复招募；宝箱、指定英雄额外奖励仍只出强化。

rules.json升级为schema 2，以recruit_chance=2500（万分比）替换recruit_levels；运行目录升级为schema 4，不接受旧格式或迁移旧状态。升级外层仍称upgrade，每张候选必须携带kind=hero/upgrade，表现与确认按单张类型处理；bonus/chest维持原上下文。历史记录在普通升级中记录实际所选类型，额外奖励仍保留原上下文名称。

招募候选均匀无放回；强化仍经roll_upgrade加权无放回。两类候选分别去重，数字ID相同的招募与强化互不排斥。刷新重新混抽，招募优先排除上组招募候选，不足时回填；强化刷新维持现有权重规则。某类没有合法候选时，使用另一类；两类都空时继续战斗，不造选项。使用现有defense.choice流，不改变RngSet算法、Save契约或Feature依赖。

验证覆盖25%卡位概率、0至3张招募、已拥有排除及死亡占位、满编、ID碰撞、前置与次数、刷新、指定奖励和宝箱；原生混合卡片输入、属性/描述和实际选卡，以及合法二十波对局。
