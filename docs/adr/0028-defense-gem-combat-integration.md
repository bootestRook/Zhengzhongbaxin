# ADR-0028：正式宝石表与局内战斗效果

2026-10-18。正式宝石表 `data/source/defense_tables/08_宝石.xlsx` 作为可编辑源表纳入 Defense 导表。每一行是一个宝石定义，运行时生成稳定的 `gem_id`、`effect_family_id`、`effect_id`、品质和允许部位；实际库存由同一宝石的多份实例组成。

宝石只在雕像页进行装备，进入关卡时形成该局的静态效果集合。效果对所有英雄默认生效，后续招募的英雄在创建时读取同一集合。装备冲突按 `(part_id, effect_family_id)` 判断；同名高品质可以替换低品质，同品质和低品质不能直接替换。宝石数值按同一效果的加算口径处理，基础属性百分比基于英雄基础值。

伤害上下文携带语义元素。火、冰、电、自然和物理增幅只作用于带匹配元素的伤害包。烈焰焚身的追加百分比伤害使用目标最大生命值与攻击者攻击力上限的较小值，作为真实伤害计算，仍由护盾吸收。

雕像按防御塔目标处理。普通直接攻击和显式允许作用于雕像的效果可以命中；持续伤害、状态跳伤、范围持续脉冲和反伤默认不作用于雕像。雕像强化、前 N 次真实受击免疫、首次低于 25% 的免伤、波次开始修复和英雄死亡修复均由领域事件处理。天罚在累计损失达到表中阈值时，以雕像中心300距离对怪物施加5秒昏迷，昏迷禁止移动、攻击和释放技能。攻速增幅只更新正式表数值，实际攻击速度暂不接入；攻击范围相关宝石仍暂缓。

当前默认测试库存为每个正式宝石定义两份实例，便于验证同一效果的多部位装备与替换；后续数量由库存系统继续扩展。
