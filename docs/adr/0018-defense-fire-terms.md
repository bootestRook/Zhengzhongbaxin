# ADR-0018：火焰术士词条库

2026-10-16，已接受。用户批准以表内200至210整体替换火焰术士旧词条，文案逐条保留原文；其他英雄定义不变。

200招募自动获得，冷却6秒、施放范围1200、蓄力1600毫秒。火球仅负责飞行，每次命中结算100%攻击力火系范围爆炸，删除旧直击、默认攻速增伤和旧分支。201至210每局各一次，按逐条权重抽取，210要求同时拥有201和202。

在现有hero_roster schema 2、catalog schema 8内增加技能的fireball能力配置和词条的fireball_mod增量配置。DefenseFireball作为defense领域内部能力模块，管理整组蓄力、目标分配和派生爆炸，复用既有弹体、伤害、状态及命名RNG。通用调用路径只按能力字段路由，不按英雄或内容ID分支。每组优先分配不同合法目标，不足时循环复用已有目标；每颗弹体独立记录命中对象。

爆炸加成按百分点相加。202使主爆炸及余烬范围乘1.8。205生成一次主爆炸范围1.3倍、伤害0.5倍的副爆炸，继承引燃与眩晕，不生成余烬或递归。206使蓄力2400毫秒、数量2；207使数量3，整组蓄力仅获得一次最大生命25%护盾，到期、中断或死亡清除。208以当前总攻速动态提供每点0.1%增伤，作用爆炸、引燃和余烬。210使每颗最多穿透命中3名不同敌人，每次都生成主爆炸，保留其余强化。

引燃5秒每秒100%攻击力火伤，重复刷新不叠层；余烬3秒每秒100%攻击力火伤，同一施法者重叠区域对同一敌人每秒至多结算一次。二者不继承爆炸专属加成。新增独立状态定义，避免修改其他英雄共享状态；仅新状态采用末次到期伤害和刷新节拍。控制与通用火系减免沿用既有伤害契约。

炎爆术使用升级弹体与爆炸动画，并添加独立的亮芯、焰环、拖尾及扩散冲击波表现。表现仅消费领域快照，不决定命中、范围或伤害；原火球和其他英雄表现不变。

纯蓄力特效采用确定性的分球位置，不使用战斗随机流；未引入新的RNG契约或全局服务。

验收覆盖非法配置、原文、前置及权重、实际血量、所有时间边界、目标不足、不同学习顺序、护盾吸收与清除、穿透命中、升级表现快照及真实选择操作；其他英雄逐条与修改前基线比较，最后运行完整工程检查。
