# ADR-0015：勇者圣盾词条库

日期：2026-10-16。状态：已接受。

用户批准替换勇者全部旧词条，其他英雄保持原定义。圣盾招募即获得，减伤50%、持续4秒、冷却10秒、范围400。坚守阵线内置冷却按最后补充改为500毫秒；每层额外减伤1个百分点，上限10层。其余前置、权重和效果以 `docs/DEFENSE_WARRIOR_TERMS.md` 为准。

`hero_roster.json` 升为schema 2，新增按英雄明确声明的 `option_sets`。显式集合整体替代该英雄旧分支，不做旧ID迁移或兼容。勇者运行词条ID使用200100至200107，`term_id`保留策划编号100至107；旧100至102的德鲁伊定义保持原值。生成目录升为schema 8。

新增词条支持 `draw_weight`、`recruit_weight`、`term_type`、`duration_up` 与 `guard`。勇者招募权重5000，其他英雄等权5000；勇者强化使用逐条权重，其他英雄继续品质权重。普通、指定英雄与宝箱均调用同一词条权重接口；既有英雄平衡权重与独立命名随机流保持不变。

`DefenseProtection` 属于defense领域，读取词条配置，在单位实例保存规则、免伤截止时间与保命可用时间；受伤叠层保存在本次圣盾状态实例中。通用执行路径按能力字段分支，不按勇者或词条ID分支。战斗时钟驱动500毫秒叠层、2秒免伤和60秒保命冷却，死亡复活不刷新保命冷却，新局创建实例时重置。

钢铁意志仅在圣盾期间阻止敌方强制位移并缩短控制状态时间，不缩短全部负面状态。威严震慑状态绑定当前嘲讽与嘲讽者存活状态。恒辉圣盾同步延长圣盾和嘲讽。致命伤保护在扣血前结算；免伤阻止普通、技能和持续伤害，且完整持续2秒。

界面保留现有固定场景，只同步新名称、描述、已学词条和实际技能参数；验证包括候选资格、权重、伤害、减控、位移、死亡复活、真实点击与三档窗口。

圣盾嘲讽明确使用圆形规则范围，与装饰特效碰撞框分离；范围强化按面积增加30%，400按平方根换算为约456.07。圣盾说明通过模板读取实例的冷却、嘲讽范围和持续时间；其他英雄保持既有描述。

同日补充：用户明确批准保留并行的强化卡直接说明、施放范围与技能表现调整，合并验收。它们由相应界面变更和ADR-0016负责；勇者词条任务不重写其他英雄词条。验收快照单列已批准的并行差异。
