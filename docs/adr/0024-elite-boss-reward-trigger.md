# ADR-0024：精英和首领必定触发掉落奖励

后续固定登场分类和当前数据格式以[ADR-0025](0025-two-elites-one-boss.md)为准；本页触发、来源和纯图标转盘原则继续沿用。

2026-10-16。用户确认只有击杀精英或首领时必定进入转盘并暂停游戏；中央显示真实来源，格子只显示填充图标。本决策覆盖 ADR-0022 中普通怪概率掉落、精英共用概率、最终首领跳过奖励及中央数量的旧约定。

Loot只接收elite、boss两类来源，每次实际死亡排队一份奖励，普通怪不抽概率也不消耗掉落随机流。队列票据及当前快照携带source，展示精英掉落或首领掉落。最终首领同样发奖，全部掉落关闭后再生成胜利结算；雕像归零仍优先失败并清空队列。奖励阶段冻结领域战斗时钟，动画、跳过和关闭不重新抽奖。

保留1至4项的50∶30∶15∶5权重、先数量后词条、真实入账、前置/次数/去重及连续奖励编号保护。词条库抽空时仍显示来源和词条已全部获得的说明，暂停等待关闭，不抽数量或伪造奖励；四档权重没有0项档位。

移除生成数据里的normal_chance及其运行时配置，保留普通强化使用的品质权重，生成目录严格升级schema10，不读取旧格式。冻结reference资料保留作来源证据，不将其旧价格字段用于当前掉落规则。

转盘中央固定显示来源，数量滚动和既定数量移至顶部状态。删除格子词条名节点，让图标填充边框内区域；上方获得结果继续显示词条原名和正文。验证普通怪不触发、精英/全部首领必触发、真实死亡、防重入、空库、结算时序、暂停及两阶段点击，并拍摄两类来源和三档窗口。
