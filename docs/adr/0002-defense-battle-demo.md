# ADR-0002：竖屏守城战斗初版

状态：接受。日期：2026-10-13。

## 背景与授权

用户在资源拆解与实机研究后，明确要求使用已有资源及热更完成初版复刻。此明确范围覆盖脚手架“不复制名称、数据或资产”的默认约束；实现代码重新编写，不复制原商业 JavaScript。证据源为 `F:/T8demo/正中靶心2_拆解_20261013/09_当前客户端补充` 和当前版本配置。资源只用于用户请求的本地研究 Demo，不声明第三方资源为项目原创或授权公开发行。

## 决策

- 单一 `defense` Feature 拥有完整局内状态。主界面、战斗和结算是它的表现状态；不增加跨 Feature 依赖或 Autoload。
- 2D 竖屏逻辑画布 960×1920，桌面默认 720×1440，保持比例。固定 UI 使用 `.tscn`，单位、弹体、飘字和选项是动态内容。
- Domain 使用 16 毫秒固定步长。倍速由表现适配器提交更多相同逻辑步，不改变伤害、RNG 顺序或冷却单位。暂停和选择不推进世界。
- 保留前 50 关原配置。统一开局采用同一英雄等级输入、无装备/宝石/符文；使用英雄自身基础修正。固定输入不承诺所有关卡均可通关，不压平关卡成长。
- 17 名有内容的英雄进入初版内容范围。战狂保留不可选择的资料缺口；缺失技能 608、1072、510 在导入审计中显式记录，不能静默替换为其他技能。
- 复用 `RngSet`、Core Entity/Attribute/Tag/Effect 和 Ability Graph 执行契约。项目索敌、刷怪、弹道与源数据语义留在 Feature。图调用稳定项目动作，动作数据来自规范化配置，不执行原始 JavaScript。
- 新增 `data/source/defense/reference.json` 作为被冻结的结构化来源，转换为 `data/generated/defense_catalog.json`。嵌套技能/波次/条件本来是有类型树，避免塞进 CSV 字符串。现有通用数据与资产台账保持原管线；新管线同样有模式、引用校验、来源指纹和漂移检查，并接入 `project.py data/check`。
- 原 PNG 动作帧转换为网格图集，保留画布、帧时长、空白帧、swing 和循环停顿。图像来源写入清单，运行时按逻辑 ID 查找。使用已有 Python/Pillow，无新增项目运行时依赖。
- RNG 流为 `defense.spawn`（怪池与位置）、`defense.choice`（成长候选）、`defense.combat`（战斗概率）和独立 `presentation.defense`。种子可重现，同一输入得到同一结果。
- 初版每次启动从选关开始，不提供中途存档恢复，不沿用示例 save。后续局内恢复必须另立完整快照契约。

## 实施与验证

先打通真实一局，再扩充同一系统。伤害、状态、死亡复活、技能前置、召唤和 Boss 门槛具有领域断言；所有 1,500 波与参考输入逐项对比。场景验证真实按钮 Intent 链，完整 `project.py check`，正常及 100/300 敌人压力场景。实机截图仅证明对应表现，不能替代机制验收。

资产预算按本次离线桌面内容实际需要分别登记，保持单图最大 4096，不为包体目标牺牲现有资产；用户未要求 Web 制品或公开发布。交付可直接运行工程和启动入口，任何导出另按 PACKAGING 检查。
