# ADR-0020：寒冰射手词条库

2026-10-16，用户已批准400至409整表替换旧多重箭词条树，以及80击退、180半径、每秒100%攻击力共五跳的箭雨。

## 决策

人工源继续使用hero_roster.json，运行目录由管线生成。策划编号400至409映射到内部200400至200409，避开其他英雄已有编号。增加技能能力ice_arrows和词条ice_mod，校验引用、概率、范围、整数上限和最终组合；不修改Save/RNG契约，不添加依赖或跨Feature调用。

独立DefenseIceArrows管理多重射击、同组命中、连击、冰冷、集中及箭雨，复用命名defense.combat随机流、领域状态、投射物和强制位移。共享调用按能力存在分发，不按英雄或内容编号分支。技能定义不可变，词条只修改所属英雄技能实例。2026-10-16用户明确词条只作用多重射击及升级形态，删除普攻接入和普通箭专用分支。

400招募自带，401可取两次，其余一次。409要求401至少一次、402、405同时拥有；旧寒冰词条从运行目录删除。技能伤害加成基于50%基础系数加算，普攻保持100%攻击力且不触发寒冰词条。基础向目标方向射出三根直线箭，相邻弹道间隔7°；齐射增加至四根，穿透额外一人。仅每次完整多重射击出手判定一次连击/箭雨、叠一次集中；连击追加一次多重射击，不再次触发这些出手被动。箭雨和折射不触发出手被动。

冰冷每次技能主箭或折射命中加一层、刷新整组5秒，五层清除后冻结3秒，冻结期间不积冰冷。集中存放在该技能实例的ice_focus状态中，按层数、截止时间、英雄生命轮次限定有效性；不再使用英雄全局属性状态或focus_status引用。仅本技能及其派生伤害结算时，攻击力按基础值每层加1%、法术强度每层加1点，仍走通用伤害、暴击与减伤接口。刷新整组4秒，40层封顶，到期和死亡失效；不改变英雄面板、普攻或其他技能。4秒持续与基础4秒冷却相同，常规叠层受限，保留用户确认时间。击退沿实际飞行方向80单位、200毫秒、场地边界截断，同次出手含连击对同目标最多成功一次，尊重已有位移免疫。

星辰之箭每次直接命中向300范围内最近另一存活可见敌人折射一次，同伤害且继承冰冷；折射无穿透、不再次折射，击退仍受原攻击组限制。升级继承全部已选强化，底栏和属性说明同步名称及图标。

箭雨触发时锁定当前目标位置，圆形半径180，持续5000毫秒，在0/1000/2000/3000/4000毫秒各造成100%攻击力冰伤；每片箭雨对每名敌人仅首次命中冻结1000毫秒。箭雨不继承主箭专属增伤、不施加冰冷或击退、不触发连击/折射/新箭雨。重叠箭雨伤害独立，同一时刻的冻结只刷新到最长截止时间。

## 验证

覆盖源表非法字段与引用、前置和次数、三类抽选与种子重放、真实扣血/叠层/到期/击退、一次出手判定与派生终止、箭雨五跳和晚入场、选卡鼠标输入与三档原生界面。完成后执行project.py check，不把视觉夹具认作正常完整对局证据。
