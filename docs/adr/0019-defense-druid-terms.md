# ADR-0019：德鲁伊荆棘护甲词条库

2026-10-16，已接受。用户批准以301、302、303、306、307、308、310、311、312整体替换旧荆棘词条，词条卡文案隐藏基础治疗和伤害的攻击力倍率，英雄技能详情读取完整技能描述并显示对应数值，保留强化增益、护盾比例、范围及时间。运行ID使用200301等独立编号，策划编号保留原值；只有301自动获得，302可选两次，其余强化一次，多个前置同时满足且不消耗。

在现有hero_roster schema 2内增加技能的thorn_armor配置与词条thorn_mod增量。显式词条库允许1或2次获取，不增加兼容或迁移路径。DefenseThorns作为defense内部能力模块管理护甲结算与花灵实体，通用路径按能力字段路由，不按英雄/内容ID分支。

按用户后续确认，整组词条只增强该英雄的初始荆棘护甲及其派生效果。编译器以初始技能能力及所属词条集合验证范围：强化必须仅绑定该初始技能，并且只能使用thorn_mod；初始项只解锁该技能，整组不允许附加英雄全局属性、被动、其他技能或独立召唤。现有运行时已把加成存放于技能实例，按实际护甲状态触发反伤与缠根；补充回归覆盖普攻、其他治疗、已持有及后来习得的其他技能和未受护甲友军，保持这一边界。

护甲基础护盾为受保护者最大生命5%，直接治疗为施法者攻击120%，反伤为施法者攻击50%的自然技能伤害。润生提高直接治疗50%，并创建独立1.5%额外护盾。基础护盾先吸收；耗尽时立即结束荆棘护甲和反伤；额外护盾保留至自身到期。受保护时命中的直接攻击（含技能）触发反伤与缠根，完全被护盾吸收仍触发，闪避、持续伤害和反伤不触发。击破的该次攻击仍结算一次反伤。缠根每层减少基础攻速5%，最高5层，重复刷新5秒。

护甲自然到期或自身护盾被击破时，木灵庇护在目标位置半径300内眩晕3秒，不附加伤害；刷新、死亡、清理不触发爆炸。状态移除增加明确原因，以区分实际到期/击破和内部替换。按2026-10-16后续确认，护甲技能沿用900施放距离，仅选择存活的其他友方英雄，优先当前生命/最大生命最低者，比例相同时按距离、单位编号排序；共生依次选择两名不同目标，无合法友军时才保护自身。

花灵是模块拥有的真实计时实体，不注册为战斗阻挡/受击单位，不产生仇恨。复用现有花类动画，领域快照提供位置和动作；表现不决定规则。花灵生成后第5秒首次触发，半径200内造成施法者攻击100%的自然技能伤害并禁锢2秒，10/15秒到期时先处理最后一跳，再移除。上限属于施法者，超限替换剩余时间最短者；施法者死亡不提前清除已生成花灵。跟随只迁移现有花灵至本次受护甲者身旁，迁移后跟随对应存活英雄，不刷新寿命或触发计时；每株为一名不同受保护者治疗最大生命10%并提供10秒30%减伤，不足两株时按实际数量结算。

验收覆盖源定义不可变、错误引用/数值、完整前置、两次上限、三类抽取权重、实际治疗/护盾/反伤/控制、末次触发、替换/迁移/死亡/新局、真实卡片输入和三档界面。其他英雄定义与修改前快照逐项比较，交付前执行完整工程检查。
