# ADR-0026：中文 XLSX 配置与怪物组子表

状态：接受。日期：2026-10-16。

按用户最新确认，以八个独立 XLSX 作为英雄属性、技能、词条、Buff、怪物、关卡、刷怪和正式宝石的人工编辑入口，怪池成员作为刷怪文件的子表，删除旧独立怪物组文件。新增工具依赖 openpyxl，仅用于读取 XLSX；工作簿初始化与编辑使用 Artifact Tool。schema 与中文列映射放在 data/schema/defense_tables.json。表格不接受公式、外链、重复主键、非法类型或坏引用。

技能主表增加完整描述并导出description，供配置识别，不改变伤害规则或词条说明来源。怪物主表直接拥有中文title/description，删除旧名称/说明文本编号入口，编译器不再从冻结文本覆盖编辑值。缺少独立原文的历史记录明确标注，不推断不存在的效果。成长与精英参数使用更明确的表头并在填写说明解释实际公式，数值和刷怪机制保持不变。

reference.json 是不可编辑的原始研究快照，不充当被表格接管记录的缺失回退。加载时整组替换技能、状态、词条、怪物、召唤物、目标和被动定义；hero_roster.json 与 level_balance.json 的人工入口删除。英雄属性单独持有最终初始属性，职业复活仍由现有规则负责。局外等级固定为 1，尚无个人升级、消耗或持久化流程，不编造数据。

刷怪行只引用怪物组 ID。组内成员保持现有怪池顺序及权重，固定登场引用单成员组且不额外抽随机数。保留现有逐只刷新、间隔随机档位、拥挤延期、精英周期、波次与升级规则，不实现参考表里尚未支持的触发器、数量浮动或分布模式。

原有模板等级增量、章节修正及累计波次成长显式映射，保留现有结果；关卡生命/攻击倍率与刷怪行生命/攻击倍率独立相乘，新增倍率初值为 1，原第 2 关生命倍率保持 0.51。倍率仅作用敌方单位，英雄与召唤物不受影响。当前运行 schema 升为 12，不保留旧格式加载路径。

导表在内存完成全部读取、引用和领域校验后，通过同目录临时文件原子替换 defense_catalog.json。失败保留原运行数据。project.py data、更新启动与打包继续走同一入口；源指纹加入七份 XLSX 和 schema。运行时只读生成 JSON，不依赖 Excel 或 Python。

验证：表格往返与旧目录逐字段对照、怪池顺序及固定种子行为、修改后真实领域属性、非法输入不覆盖、双击入口、各工作表视觉抽查，以及完整工程检查。无导出包交付，本次不执行平台发布验收。
