# ADR-0017：五英雄词条保留用户原文

日期：2026-10-16

## 决策

勇者100至107号词条使用用户原始词条表的描述。圣盾的-X%按用户确认改为-50%；坚守阵线按最新要求省略内置冷却说明。不得追加范围、冷却换算、死亡复活等实现细节。

这一约束适用于当前五名英雄的全部47项词条。以用户表格的原句为正文，不能用战斗实现说明替换，也不能自行补充结算过程、额外攻击边界、折射继承或叠层刷新规则。后续明确修改优先于原表：德鲁伊隐藏基础治疗与伤害倍率、保留强化数值，花灵范围占位采用已确认的200；火焰术士保留已确认的火系伤害补充；刺客即死沿用用户最新提供的原句。寒冰射手采用补充概率后的表格。

招募、强化、宝箱、属性、图鉴与底栏统一读取静态Definition的描述。删除仅用于勇者圣盾的description_template字段、校验和运行时拼接路径，避免底栏再次改写原文。不保留兼容处理。

本次仅修正文案来源与展示契约；战斗规则仍由各能力模块负责。替代ADR-0016中勇者底栏说明自动拼接范围、冷却和持续时间的做法。

## 验证

逐条核对源数据和生成数据的原文，确认其他字段未变；验证招募与底栏读取相同描述，执行完整工程检查。
