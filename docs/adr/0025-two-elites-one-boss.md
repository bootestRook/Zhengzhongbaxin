# ADR-0025：固定登场改为两名精英与一名首领

2026-10-16。用户将每局三次固定首领登场改为前两次精英、最后一次首领。第8、14、20波及原单位资源、技能和数值配置沿用，波内原有精英节奏保留。

生成目录将含混的bosses数组改为显式encounters记录，依次标记elite、elite、boss；源规则boss_waves改为encounter_waves。源规则严格schema5，生成目录schema11，不保留旧字段或旧格式兼容。冻结reference的Boss配置仅作为原单位和站位参数输入。

固定角度登场不再抽取不会使用的随机横坐标，仍使用既有命名随机流；相同显式种子在新规则内可重放，不保留旧版本抽样序列。

固定登场单位通过独立工厂入口创建，实例kind从记录读取，使用原固定登场成长配置；普通波内精英仍使用原精英额外成长。所有单位带encounter_wave，普通怪及波内精英为0，固定单位记录其波次。死亡仅把固定登场波次记入encounters_cleared，不增加普通波次击杀数；删除bosses_dead旧计数，胜利要求三个固定登场均已击败并完成待发奖励。乱序击杀不会提前胜利，也不会误标结算节点。

精英身份真实参与掉落、索敌、碰撞与表现规则，前两次显示精英掉落，最后一次首领掉落；保留自动暂停、1至4项权重、原词条和两阶段点击。主页说明、怪物资料及结算节点展示两精英一首领。验证50关生成分类、原数值保留、真实刷怪与死亡、普通波内精英不推进固定进度、乱序击杀、最终发奖后胜利及三档界面。
