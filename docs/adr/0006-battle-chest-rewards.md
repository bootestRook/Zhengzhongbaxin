# ADR-0006：局内宝箱与预抽词条

状态：采用。日期：2026-10-14。

按当前客户端 `EquipPool`、`EquipBoxCom`、`LevelBuffSelectMgr` 和 Boss 选择页核对，宝箱掉落时确定一个词条，领取时展示固定中间卡。删除原有宝箱三选一及刷新路径。

- 同 defense Feature 的 `DefenseLoot` 管理预抽内容、品质、英雄平衡权重及失效词条替换/拆箱；状态持有者为本局 Session。
- 玩法随机使用注入的 `defense.loot` 命名流；表现抖动不消耗玩法流。新局重置宝箱序号及英雄权重。
- 品质抽取、普通掉落概率和非最终首领的箱子数量使用现有冻结 `function_price` 数据，经既有管线生成 `loot` 配置；不改变数据格式版本或保存契约。
- 领取不能再抽三个候选或刷新；确认固定词条后通过 Upgrades 接口生效。暂停/选择期间不能领取，重复领取不能重复发放。
- 50×41 箱体、品质光柱及悬浮抖动读取现有图集与组件尺寸；移除点击领取文字。绘制与命中共用现有世界投影。

本次不新增局外装备、服务器奖励或付费入口。来源核对及验证记录置于 `validation/defense/`。
