# ADR-0009：五人、二十波与职业复活规则

状态：接受。日期：2026-10-14。

用户批准体验规则调整：五名英雄分别在局内 1/2/4/6/8 级招募；二十波、二十级；三位首领在 8/14/20 波；战士、守护、刺客死亡后 20 秒复活，法师、射手、辅助 10 秒；雕像仅作为防守目标，雕像强化退出抽选。

后续ADR-0010取消上述固定招募等级，改为开局招募第一名、后续升级按25%招募/75%强化混抽；其他体验规则继续有效。

原始 reference.json 和 combat.json 保留为来源证据。新增人工编辑的 rules.json，集中存放本项目已确认的规则和五人站位。编译器严格验证后生成 schema 3 运行目录：取原前二十波普通刷怪及成长，保留原三位首领模板并重排波次；英雄标签中的职业编号决定属性 23 的完整基础时间；追加同排五人站位。运行数据不包含旧雕像强化或旧复活基准；不接受 schema 2、不迁移旧状态。

复活从死亡瞬间按战斗时钟计时，死亡动画包含在时间内；保留英雄复活技能及满血复活。出生和复活在雕像前方出现，领域 AI 在归位途中只优先索敌范围内的敌人，敌人消失后继续归位。表现读取快照，不能决定移动或复活结果。新规则仍使用现有命名随机流，不改变 RNG/Save 契约或模块依赖。

验证覆盖全部可用英雄的职业计时、雕像不扣血、五人上限与同排五人、归位途中的攻击和继续移动、合法招募及完整二十波回放，以及五槽鼠标交互和三种窗口尺寸。原客户端规则验收记录作为历史来源，不能再称为当前玩法规则。
