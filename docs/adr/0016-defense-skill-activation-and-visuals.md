# ADR-0016：初始技能施放范围与表现寿命

日期：2026-10-16。状态：已接受。

用户要求圣盾按4秒，空场技能新增施放范围，修复荆棘施加特效，并调整冰、电技能颜色。

技能定义新增可选正数 `cast_range` 与六位 RGB 字符串 `visual_tint`。未声明施放范围的技能继续通过自身目标规则决定是否起手。声明者在动作和冷却开始前，必须找到英雄位置圆形范围内存活、可见且满足交战区规则的敌人；圆周计入，不加目标体积。2026-10-16用户纠正：施放距离和效果范围独立，`radius_bonus` 不扩大 `cast_range`。圣盾施放距离按用户后续要求缩短至200，嘲讽强化仅作用于嘲讽子技能，效果范围面积增加30%，400按平方根换算为约456.07；火球术施放门槛1200。火球仍受交战区Y≥850（首领收尾例外）与弹体索敌规则约束，起手后蓄力1600毫秒并重新选取目标，因此圈内有敌人不等于立即出手。起手后沿用现有蓄力和命中规则，不锁定敌人的存活或位置。

类型7的连接特效将规则脉冲与显示寿命分开。每次脉冲仍按既有次数与间隔结算；末次脉冲后保留 `movie_effect` 声明的可见时长，不重复治疗或施加状态，持续跟随双方施法点。其定向命中不依赖面积碰撞，显示宽度不再套用 `damage_range / baseSize`，长度仍随双方距离伸缩。荆棘施加特效设为0.4秒，护甲仍10秒。

`visual_tint` 通过战斗快照传给图集，领域仅传递字符串，不依赖渲染类型。表现层按原像素最大通道保留明暗及透明度、替换色相，并缓存小图帧；避免深蓝箭矢叠乘后仍无法辨识冰色。冰箭使用冰青色，刺杀使用电光金黄，保留既有形状、墨线、伤害与控制规则。荆棘连接宽度从原图0.1倍调为0.3倍，并使用自然绿。源数据校验非法范围和颜色；不新增全局服务或依赖。
