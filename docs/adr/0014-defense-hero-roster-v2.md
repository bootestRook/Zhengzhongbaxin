# ADR-0014：五英雄新版设定

日期：2026-10-16。状态：已接受。

用户批准按所附五英雄表制作新版，随后明确普攻间隔从完整动作结束后开始计算。本决策替代 ADR-0012 的双初始技能规则。

五名英雄为勇者、火法师、德鲁伊、寒冰射手、闪电刺客。每名仅有表中一项初始技能；旧第二技能及其独立强化树退出运行目录。保留角色图资源、内部资源 ID、基础属性和有关强化分支。表中编号是策划顺序，不重编号已有资源。

以 `data/source/defense/hero_roster.json` 统一声明五英雄身份、普攻等待时间、初始技能和必要的定义覆盖。移除旧 `hero_skills.json`，不提供旧格式兼容。编译器复制来源数据后应用覆盖，验证引用，运行时只读生成目录。

勇者/闪电刺客的普攻动作完成后等待1000毫秒，其余等待2000毫秒。攻速改变动作速度，也按原基础攻速比例改变等待时间；基础状态严格使用表中间隔。技能独立计时，不代替普攻。

圣盾每10秒施放，范围嘲讽及50%减伤持续5秒；火球术6秒；荆棘15秒、护甲10秒；多重箭4秒、至多三个不同目标、每箭50%攻击力的冰伤；刺杀8秒、电伤。未给出的火球/荆棘/刺杀倍率、范围和动作时序沿用相关技能现值。元素同时进入普通攻击和技能伤害上下文。

固定单技能按钮保存在场景中，删除第二技能控件及双技能布局分支。属性、招募、底栏、图鉴和气泡共用当前定义。验证覆盖真实技能效果、动作后等待、持续与到期、伤害元素、不同目标及真实点击链。
