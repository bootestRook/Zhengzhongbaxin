# ADR-0027：共用领域控制的战斗测试场

状态：接受。2026-10-16，用户明确批准实施讨论中的完整测试场。

## 决策

- 独立开发场景实例化 `scenes/main.tscn`，保留真实画布、HUD、动画、音频和领域战斗。正式入口不增加测试按钮。
- `defense/domain/lab` 持有测试配置、操作、检查和记录。人工 UI 与无界面运行器调用同一接口；UI 不写领域对象。
- 测试 Session 继承正式 Session，只替换环境推进与测试控制模块。正式战斗推进抽取环境/结算两个扩展点；伤害扣血抽取一个扩展点，默认语义完全保留。
- 不死靶正常结算减伤/护盾，记录实际结算伤害，生命在每次扣血时补满，阻止死亡与斩杀；无敌靶拒绝伤害。两者均不证明致死机制正确。
- 清除删除单位及相关状态/弹体/延迟行为，不执行死亡触发。击杀使用正式死亡接口，标记人工操作；技能专属击杀必须由真实攻击/技能完成。
- 属性修改作用于 Instance 基础值；已存在的词条/Buff 修饰继续参与最终值。词条增删、配置加载使用新 Session 重建，清除所有历史效果。
- JSON 测试文档版本为 1，包含配置、顺序操作、断言、内容与代码指纹。拒绝旧版本/无效输入，不提供迁移。此文档不是游戏 Save；不改变游戏 Save/RNG 契约。
- 复现从初始配置按固定16ms步进重放。配置变更重建后重新建立记录起点；不宣称支持任意中间快照恢复。记录有数量上限并显式报告截断。
- 默认隔离自动波次、选卡与奖励；可独立启用刷怪或完整关卡流程。自动补怪独立控制。测试专用模块和场景从普通导出排除。

## 验证

领域用例覆盖输入失败、清除与击杀区别、不死/无敌、词条合法性与移除、属性读回、确定性重放；现有五英雄规则测试继续运行。补充真实场景输入、多尺寸画面、怪物目录与词条覆盖、压力和重开检查。新增测试选择入口及发布排除触发一次L3完整检查。截图/自动断言/人工观感分别报告。
