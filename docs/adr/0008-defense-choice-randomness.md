# ADR-0008：每局种子与三选一抽取

状态：采用。日期：2026-10-14。

固定日期种子令重启后的首局重复；整池洗牌也未表达当前客户端的英雄与品质概率。按 `refreshHero`、`getExcludeBuff`、`getWallBuff` 和 `refreshBuffPool` 的规则修正。

- App 组合根为每次普通开始/重试产生新的系统随机种子，注入 Session；Session 不访问系统时间、全局随机或场景。移除固定日期及运行次数递增的种子路径。
- 显式种子用于重放和测试；同种子与相同操作继续确定性重现。沿用现有 RngSet 算法及 `defense.choice`、`defense.loot` 命名流，不把随机性放入界面动画。
- Choices 持有本局候选池资格、英雄概率和上一组英雄候选。英雄逐张无放回抽取，刷新优先排除上一组，池不足时重新补回上一组可用英雄。
- 普通强化逐张按英雄概率与品质权重抽取并排除本轮已出词条；指定英雄的额外强化使用其可用池均匀抽取；雕像从合法负 isNew 池均匀抽取。前置、互斥、次数与 isNew 组上限统一检查，numTable 模板不进入候选。
- 英雄概率从 Loot 移到 Choices；Loot 调用同一资格与加权抽取，继续使用独立 `defense.loot` 流。删除原有重复权重所有者，不加兼容路径。

局外可用英雄仍采用 Demo 已声明的固定输入，不接服务器、广告、装备定向召唤或调试固定英雄开关。本次不更改固定卡片结构或表现风格。
